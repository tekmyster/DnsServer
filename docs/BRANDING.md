# Tectanium DDI

Tectanium is the presentation name of this DDI fork. The console, sign-in, browser titles, favicon and public DNS setup page use this name. Technitium attribution, licenses, service identifiers, configuration paths and API contracts remain intact. About distinguishes the upstream DNS engine version and community from Tectanium support.

The mark is a geometric T assembled from three separated pieces representing DNS, DHCP and IPAM operating together. Its solid shapes remain readable at 16 pixels. Use the supplied SVG for scalable display and the ICO for legacy favicon requests. The charcoal tile provides a consistent background on both light and dark surfaces.

The default theme is dark grey: charcoal `#1c1e20`, surfaces `#242628` and `#292c2f`, graphite `#3b3f43`, silver `#d6dbe0`. Routine controls and metrics are neutral; green, amber and red retain their operational meanings. Chart series retain distinct colors so operators can distinguish datasets. Explicit light, amber and system preferences are retained; a new browser defaults to dark.

Branding does not imply new production qualification or feature completeness. The existing feature matrix remains the source for implementation status.
