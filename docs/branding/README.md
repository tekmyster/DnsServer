# teQnatium logo assets

The original is the master three-part T on a charcoal tile. SVG files are scalable originals; PNG files are 1024 × 1024 exports. Preserve the originals when exploring new directions.

| Variant | SVG | PNG | Use |
| --- | --- | --- | --- |
| Original | [SVG](teqnatium-original.svg) | [PNG](teqnatium-original.png) | Default brand and application icon |
| Light | [SVG](teqnatium-light.svg) | [PNG](teqnatium-light.png) | Light tile |
| Silver | [SVG](teqnatium-silver.svg) | [PNG](teqnatium-silver.png) | Transparent mark on dark surfaces |
| Graphite | [SVG](teqnatium-graphite.svg) | [PNG](teqnatium-graphite.png) | Transparent mark on light surfaces |

Do not stretch the mark, rearrange its three pieces or substitute status colors. Keep at least eight units of clear space around it on the 64-unit design grid. The console and public DNS page use a copy of the original SVG; ICO exports supply 16, 32, 48 and 64-pixel favicons.

The Q mark is the current teQnatium identity. Earlier `tectanium-*` SVG and PNG originals are preserved unchanged for historical use. Compatibility image paths in the console render the current mark.
